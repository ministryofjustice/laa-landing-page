Request for Full Name to be reactivated

! Warning This form submits a reactivation request on behalf of a provider admin.

This user has been deactivated by the Legal Aid Agency. You need to request for their account to be reactivated.

You should only do this when:

  • the provider admin has lost access and cannot request this themselves
  • there is only one provider admin at the firm
The person requesting reactivation doesn't meet these criteria

If the person requesting reactivation does not meet these criteria, ask another provider admin at the firm to submit the request, or ask the deactivated user's provider admin to submit a reactivation request themselves.

Before you start, ask the deactivated user to provide a justification for:

  • Why they did not use their SiLAS account for that length of time
  • What has changed that means they now require regular access
